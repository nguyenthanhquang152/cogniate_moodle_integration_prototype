## Goal

Teachers can cancel the picker: the app signs an empty Deep Linking response and posts it to the LMS. On a channel whose LMS handles several items, the teacher can pick 1 to 20 courses at once. When the placement does not take graded items, the picker says so and makes no Deep Linking call.

## Scope

In:
- D3a app: a "Cancel" button on the picker page and on the "No course is published" page. `POST /tool/picker/{pickerId}/cancel` has the checks of the picker POST (exists, unused, unexpired, `Origin` = `PUBLIC_APP_URL`). It calls `POST /api/deeplinking` with `contentItems: []` and `options.message = "No course was added."`, posts the JWT to the return URL like a pick, marks the picker used, and makes no pick row.
- D3b server rule: when the channel has `content.multiple` false, or the launch has `acceptMultiple` not `true`, the picker POST accepts **exactly one** id; two or more give the `400` page `PUBLICATION_NOT_AVAILABLE` and post nothing (A-LAB-04; A-T0-11: Moodle hides the grade settings for several items).
- D3b: checkboxes only when `content.multiple` is true **and** `acceptMultiple` is true, else today's radio list; 1 to 20 publication ids, each of the picker's connection and `available`; items in list order; each item with its own `lineItem`.
- Pick records: one `picker_pick` row per picked publication in the transaction that marks the picker used; a single pick also writes `picker_session.publication_id`; `launchStats` and the picker retention exception read `picker_pick`.
- D3c app: with `acceptLineItem === false` and `content.ungraded` false, the page `PLACEMENT_NOT_GRADED` ("This {LMS} placement does not take graded items. Use {LMS}'s graded placement to add a Cogniate course.") and no Deep Linking call.
- Page headers of security delta §5 for the cancel auto-submit and `PLACEMENT_NOT_GRADED`.

Out: ungraded items (LA-E3-08, Should); the LTI service rules (LA-E3-04).
