## Goal

Add the four Should jobs of LA-ADR-06 D11 and the operator endpoints that list jobs and start one on demand. These jobs reduce manual work (key expiry warnings, scheduled signing-key rotation, data purge) but no Must feature depends on them.

## Files

| new `services/lti-service/src/http/operator/jobs.ts` (S1; jobs endpoints) | `packages/shared/src/jobs.ts` (R) |

Needs from other lanes: none.

## Scope

- In: `api-key-expiry` (hourly; logs and counts keys that expire within 14 days; feeds `lti_api_key_expires_in_seconds` if LA-E5-17 ships); `idempotency-cleanup` (hourly; records older than 24 h); `signing-key-rotation` (daily; only accounts with `autoRotate: true`, default false); `account-purge` (daily; closed accounts older than `closedRetentionDays`, default 30, LA-H4); `GET /operator/v1/jobs`; `POST /operator/v1/jobs/:name/run`.
- Out: the Must jobs (LA-E5-19); `key-rewrap` and its endpoint (LA-E5-09).

## Design notes

- Ratified (BD-A2-82): `account.purge` `details.counts` is a list of `{table, rows}` (a list, because `redact()` hides keys that end in `key`); the log line `job_run_request_failed {job, trace_id}` when `runNow` rejects. Runbook: operability §8a.
- Spec gaps (BD-A2-65 to BD-A2-70; LA-ADR-06 D2, D7, D11): (Q1) `autoRotate` is a stored account field: LTI migration `019` `tool_account.auto_rotate`, `PATCH /operator/v1/accounts/:id {autoRotate}` (account files are S1's in B3); no environment list. (Q2) `CLOSED_ACCOUNT_RETENTION_DAYS`, default 30, ≥ 1, counted from `status_changed_at`. (Q3) The purge scope as listed in D2; it keeps the tombstone and the audit rows, and writes one `account.purge` audit event per account in the same transaction. (Q4) The rotation job writes the route events with actor `system:signing-key-rotation`, never forces, skips accounts that are not `active`; `SIGNING_KEY_ROTATE_DAYS` ≥ 8. (Q5) `POST /operator/v1/jobs/:name/run`: `503`, `409`, `404`, `202` as in D11 "On-demand runs". (Q6) `api_key_expiring` lines and `job_run` counts `{expiring}`.
- `POST /operator/v1/jobs/:name/run` calls `JobRunner.runNow` (LA-ADR-03 D7). Answer `202 { job, traceId }`, or `409 JOB_RUNNING` when the run is `skipped_lease`. One `job.run` audit event per call.
- `signing-key-rotation` uses the D7 rules: make `next` at active age ≥ `SIGNING_KEY_ROTATE_DAYS − 7`; activate at ≥ `SIGNING_KEY_ROTATE_DAYS` and only after the publish lead time.

| AC-LA-E5-20-06 | `account-purge` deletes the rows of an account closed 31 days ago and keeps the rows of an account closed 29 days ago; `idempotency-cleanup` deletes records older than 24 h only. | UNIT |
