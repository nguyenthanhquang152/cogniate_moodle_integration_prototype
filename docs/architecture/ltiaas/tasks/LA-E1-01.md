## Goal

Today one unknown `lms` value in `GET /api/providers` breaks the app's provider list (`services/cogniate-app/src/clients/lti-client.ts:55`, R3 S32). After this step the app accepts any `lms` string and ignores a profile that no adapter owns. Behaviour for today's answers does not change.

## Scope

- In: the open string type for `lms` in the providers answer; the ignore rule with its log line.
- Out: the registry and the new wire fields (LA-E1-02, LA-E1-06, LA-E1-10).

## Design notes

- The log line `channel_profile_unknown {profile}` is written at most once per process and profile id (app API delta §2, §8).
