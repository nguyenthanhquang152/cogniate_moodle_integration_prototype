## Goal

The AGS score delivery becomes the first `RecordReporter`, `lti-ags`, in its own driver folder. The HTTP-to-outcome table moves into the reporter; `packages/tracking` keeps the neutral rule "outcome → status and next try". A `429` with `Retry-After` pauses only its partition without counting a try. `POST …/results/refresh` needs a reporter with read-back.

## Scope

- In: `prepare`, line item lookup, `beginSend` before the remote call, the mapping table (D5), `partitionKey` (platform id; platform id + deployment for a shared platform), `throttled` with `not_before` on the partition, `dispatch_throttled` log, read-back guard `records.readBack`, disabled rules by authority (D6, D8), `policy` limited to `bestResult` (F4.7: `everyRecord` is reserved).
