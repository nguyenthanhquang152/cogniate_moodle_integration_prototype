## Goal

When a library exports a setup artifact with an embedded key snapshot (today only the Canvas developer key JSON with `jwk=inline`), the app records the `kid` of that key on the connection. The health view (LA-E6-02) compares it with the active signing key, so an admin knows when to paste a new JSON.

## Files

| the kernel setup-artifact mount in `services/cogniate-app/src/kernel/**` (writes `artifact_key_kid` through the connection repository) | `apps/portal/**` (P) |

## Scope

In: an export with an inline key writes `connection.artifact_key_kid` = the `kid` of the embedded key; an export with `jwk=url` writes `NULL`. The JSON answer does not change. Out: the health view and its warnings (LA-E6-02).

## Design notes

- The column name is generic on purpose (LA data model §5a): the kernel writes it, and the channel only reports the `kid` it embedded.
