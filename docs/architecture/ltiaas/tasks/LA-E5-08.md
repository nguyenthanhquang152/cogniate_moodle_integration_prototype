## Goal

One key provider port in `packages/shared` holds all key material. It seals values with a versioned envelope and associated data that binds each blob to its row, and it derives purpose subkeys. Today's stack starts with no new setting, and every existing service key keeps its exact value.

## Scope

In:
- The `KeyProvider` interface of LA-ADR-06 D6 and the local key-ring provider (`kind: local-keyring`).
- Blob format `"cgk1"` with the key version and a wrapped data key; AES-256-GCM; legacy blobs (no header) open with the version `legacy`.
- Associated data `lti:<table>:<column>:<tool_account_id>:<row key>` for `tool_key.private_jwk_encrypted` and the sealed `registration_session` columns.
- Key ring at `LTI_KEYRING_FILE` (default `/run/secrets/lti/keyring.json`; compose mounts `infra/.secrets/lti/` read only). No file: `LTI_MASTER_KEY` (or `LTI_MASTER_KEY_FILE`) is version `legacy`, active.
- `mac(purpose, version, input)`: `mac('service-key', 'legacy', …)` = today's subkey (`services/lti-service/src/store/service-keys.ts:24-38`); other versions use HKDF-SHA-256 with info `cogniate-lti/<purpose>/<version>`.
- Column `service_key.derivation_version` (default `legacy`).
- `ready()` fails, and the service logs `key_provider_not_ready {version}`, when a version that a row uses is missing from the ring.
- `open` failure logs `key_open_failed {table}`; the API call answers `500 INTERNAL_ERROR` with the trace id.
- Cache of the decrypted active private JWK per kid for at most 10 minutes.

Out:
- `GET /operator/v1/key-provider`, the re-wrap job and the legacy refusal (LA-E5-09).
- `/readyz` and its `503` (LA-E5-17). Secrets-from-file rules of the `production` profile (LA-E5-21).
- App sealed columns (`APP_MASTER_KEY`; LA-E5-22). Cloud KMS adapter (LG).

## Design notes

- New blobs always use the `"cgk1"` form with the active version. The re-wrap of old blobs is LA-E5-09.
- The service-key value is security-critical: generation-0 values must stay byte for byte (M1 rule). Keep a fixture of today's values in the unit tests.
- No behaviour change on the wire (LA-IC-10: no row changes for E5 D6).
