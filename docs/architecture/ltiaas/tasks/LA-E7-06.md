## Goal

QA builds the conformance kit K1: one suite per port (K1-LAUNCH, K1-DL, K1-AGS, K1-NRPS, K1-REG, K1-CAP, K-HYG) with no channel name inside, driven by one fixture file per channel. The kit computes the expected case list from the fixture before the run and fails on a missing or extra case. The three baseline channels are the positive controls.

## Scope

- In: the suites and cases of TEST-STRATEGY §2.4; fixtures for the Moodle-shaped standard, Canvas and Blackboard channels (values from the design tables, each with its source); the `coveredBy` rule; the N/A rule; the `notBuilt` rule; the pass rule of §2.6; the per-channel evidence table.
- Out: fixtures and runs for `lti-generic` (LA-E2-04 AC) and `brightspace` (LA-E2-05 AC), which reuse this kit.

## Design notes

- `kit/lib/` imports the M1 helpers; it never copies them (TEST-STRATEGY L11).
