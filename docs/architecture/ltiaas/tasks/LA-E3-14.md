## Goal

The channel values for ungraded placements (D-11). `canvas` and `lti-generic` get `content.ungraded: true`; `moodle` and `blackboard` stay without it. The Canvas developer key JSON gets one more placement, `link_selection`, whose target carries the marker `cogniate_placement=ungraded`. LA-E3-08 (L, picker rule) and LA-E4-08 (R, records) use these values.

## Scope

In:
- `content.ungraded: true` for `canvas` and `lti-generic`.
- The Canvas JSON (`jwk=url` and `jwk=inline`) gets the placement `link_selection` with `message_type` `LtiDeepLinkingRequest` and a `target_link_uri` = the Deep Linking URL plus the query `cogniate_placement=ungraded`. Every other JSON member stays.

Out: the picker rule (LA-E3-08); the `graded` rule and the results text (LA-E4-08); Blackboard (no value until a BLACKBOARD-LIVE check).
