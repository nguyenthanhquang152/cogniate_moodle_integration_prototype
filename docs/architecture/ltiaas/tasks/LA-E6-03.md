## Goal

An LMS administrator can prove control of the LMS without a Cogniate operator. A signed Deep Linking launch with an institution or system administrator role shows a one-time code in the LMS. The library user redeems the code in the portal, and the grant engine commits the binding. This is the reserved third authority `verifiedAdminLaunch`.

## Scope

- In: the strategy; rules 1–7 of LA-ADR-08 D3; the code page (no form, no button, CSP as the picker page with `form-action 'none'`); the verify route and its errors; the audit event `binding.verified_admin_launch` (actor type `user`, the portal user id); the 7-day clean-up.
- Out: Blackboard (operator only, LA-ADR-08 D2); Moodle manual (LA-H23).

## Design notes

- Rule 6: the record becomes active and a code is shown only when LA-ADR-07 rule A6 (I-SELF) holds for the staged values, or each value is a fixed value of a named profile. Else the page says "This connection needs a Cogniate operator approval" and shows no code.
- LA-IC: none for the baseline (a new authority only; the baseline manifests do not use it).
