## Goal

A small tool that uses only the public LTI service API (no app code) shows every tool-side flow that the public 1EdTech certification test areas need: resource link launch, Deep Linking, AGS line items and scores, NRPS. It lets 1EdTech certify the service itself, if LA-H9 chooses that shape.

## Files

| May edit | Must not edit |
| --- | --- |
| New `apps/reference-tool/**` (a new workspace with its own `package.json`) | Every product file outside the new folder; root `package.json` and `package-lock.json` (K: the workspace entry by RQ-1) |

## Scope

- In: one tool account of its own; launch page, Deep Linking picker with one fixed item, a score post, a members list; a README with the test-area map.
- Out: the 1EdTech submission (human step); any change of the LTI service API.

## Design notes

- The tool calls only documented routes of the LTI service contract and its LA delta. A route that is missing is a finding for A2, not a new private route.
