## Goal

Prove once that the pilot can restore from the cold backup of ADR-012 §8 with the key ring from escrow. The drill records the measured recovery time (RTO) and the backup age (RPO) as evidence for LA-H8. The task changes no product code and no storage command (LD-3).

## Files

| May edit (exclusive) | Must not edit |
| --- | --- |
| QA-E2E evidence under `docs/reviews/LA-*/` (path chosen by the Lead) | any product file, `infra/**`, any storage command (LD-3) |

Needs from other lanes: Docs writes the runbook text from [operability §7](../operability.md#7-backup-and-restore) in E8; this drill checks it.

## Scope

- In: one backup with `npm run stack:data-backup` while both services are stopped; the backup record (key version ids, never key material); one restore into a scratch compose project with its own `COMPOSE_PROJECT_NAME`, `PUBLIC_PORT` and `STACK_SUBNET`; readiness; one simulator launch and one score dispatch; times.
- Out: an online backup (not in LA); the RPO and RTO targets (LA-H8 decides).
