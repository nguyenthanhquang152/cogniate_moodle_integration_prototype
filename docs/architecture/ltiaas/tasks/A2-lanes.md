## 2. Notes for the ownership matrix

1. **Wave-sliced files.** Some files change owner between waves; one lane owns each file in each wave: `http/routes/platforms.ts` (S in B1 for audit writes, then L in B3 for E2-K and LA-E3-12); `lti/codes.ts` (S in B1 for the page codes `RATE_LIMITED`, `TOOL_ACCOUNT_SUSPENDED`, `REGISTRATION_SESSION_LIMIT`, then L); `store/registrations.ts` (S in B2 for the key provider, then L in B3 for E2-K); `store/retention.ts` (L in B2 for `storage_check`, then S in B3); app `tool-pages/launch.ts`, `tool-pages/picker.ts`, `domain/launch.ts`, `domain/pickers.ts` (K, then R, then L in B3, README §6a order).
2. **Mount lines.** New route modules and handler lines of other lanes go through the owner of the mount file: LTI `http/app.ts` (S) for `platform-check.ts` and the `Retry-After` header line of LA-E5-14; app `app/server.ts` (K) for `connection-check.ts`, `connection-health.ts`, `admin-launch.ts`. The task names the one line it needs.
3. **Value changes in K files.** E3 and E6 capability values in `packages/channels/*/manifest.ts` (`content.multiple`, `content.ungraded`, `setup.connectionCheck`, the Canvas `dynamic` method) are sent to K. Only LA-E3-07 is a K task, because D-8 (Must) is mostly K files.
4. **Catalogs.** `services/lti-service/src/api-errors.ts` (error codes) and `packages/shared/src/logger.ts` (redaction list) are owned by S from B1; L sends `PLATFORM_RATE_LIMITED` (LA-E5-14) and the redaction name `storageValue` (LA-E3-02) to S.
5. **Shared export file.** `packages/shared/src/index.ts` gets one export line from LA-E5-08 (key provider) and one from R (jobs). The matrix names its owner.
6. **No task** for: F5.9 connection secrets port (shape only, LB or LF); LA-ADR-05 D8 new-window launch (decision only; Moodle deferred, Canvas and Blackboard unchanged); LA-ADR-07 D2 authority rules (A1 builds load check 6 and I-SELF in E1 and E2-K; so these design points are ACs of A1's tasks: AP-07-03 (F3 import rule, E1 S2), AP-07-07, AP-07-08, AP-07-10 (load check 6, E1), AP-07-11 (I-SELF K1 negative case, E2-K F2.11)); LA-ADR-07 D6 threat rows (Reviewer-A maps each row to an AC at each gate).
7. **A1 task ids.** "E1 S3", "E4 placement task", "job runner (R)" and "E2-K" name A1's steps; A1 replaces them with task ids in `epics.md`.
