## Goal

Rewrite once the frozen assertions that compare closed lists or whole objects of profiles, providers, LMS entries, cards and simulation profiles. After the rewrite, a new channel or an additive field does not break M1 or M2, and every baseline element is checked at least as strictly as before. This is the only assertion change that plan measure 3 allows outside an `LA-IC` list.

## Scope

- In: the E0 scan at G-BASE; rows 1–8 of TEST-STRATEGY §4.3; the probes that show strictness and openness.
- Out: assertion changes of an `LA-IC` (plan LD-9, at the task that ships it).

## Design notes

- "Belongs to a registered channel": the test reads the channel of each extra element from the answer itself (`channel` on each profile and entry, LA-IC-01) and checks that the channel id is in `GET /app-api/lms-providers`. Before LA-E1-06 and LA-E1-10 add the `channel` fields, no extra element exists, so the rule is not reached at G-BASE.
- Rows 4 and 5 need no change: the six legacy flags and the `details.capability` values stay byte for byte (LA-ADR-01 D3).
