## Goal

With `STACK_PROFILE=production`, the LTI service refuses to start when a setting is unsafe for production. Every LTI service secret can come from a file. The `default` and `acceptance` profiles keep today's behaviour.

## Files

| May edit (exclusive) | Must not edit |

| `services/lti-service/src/config.ts` | `services/cogniate-app/src/config.ts` (R in B1–B3, K in B4 by the matrix; this task does not edit it; `APP_MASTER_KEY_FILE` comes with LA-E5-22; epics OI-4) |
| `packages/shared/src/config.ts` (the `*_FILE` reader and the shared checks) | `packages/shared/src/knobs.ts` (read only; this task calls it) |
| | `infra/**` (no compose change: the production profile is not used in the dev stack) |

Needs from other lanes: none. The app rule "`APP_JOB_RUNNER` on in both web and worker" is A1's (LA-ADR-03 D7).

## Scope

- In: refusal rules (exit 1, one line `config_refused {reason}`): a test knob is active; `LTI_PROVIDER_SIMULATION=on`; `OUTBOUND_PRIVATE_HOST_ALLOWLIST` is not empty; `LTI_MASTER_KEY` set as an environment value; `TRUSTED_PROXY_CIDRS` is empty; the operator listener binds to a non-loopback address. `*_FILE` forms: `LTI_MASTER_KEY_FILE`, `LTI_KEYRING_FILE`.
- Out: the app part (`APP_MASTER_KEY_FILE`, LA-E5-22); `/healthz` in production (LA-E5-17).

## Design notes

- Review fixes (BD-A2-77 to BD-A2-80; LA-ADR-06 D12 "Build rules"): ring-only start through `readStartupKeys(env)` in `keys/key-config.ts` (RQ-2 for this S2 file); `loadConfig` drops the master-key check; the ring must hold `legacy`; a master-key setting next to a ring must equal its `legacy` key; `loadKeyProvider` takes the ring that was read. `readSecretFile` in `packages/shared` (fstat on the opened descriptor; no group or world bit; refuse in production, warn otherwise), used by `readSecretSetting` and the ring read. The fixed messages of operability §2 "Production refusals". `readSecretSetting(..., { hexKey: true })` for every master-key read. Unit tests: a ring-only production start works; a ring without `legacy` stops; a `0644` secret file stops production and warns in default; the upper-case `LTI_MASTER_KEY` and a lower-case file of the same key are equal.
- `reason` values: `test_knob_active`, `simulation_on`, `private_host_allowlist`, `master_key_in_env`, `no_trusted_proxy`, `operator_bind_not_loopback` (one per rule; the design names the rules, this task fixes the strings).
