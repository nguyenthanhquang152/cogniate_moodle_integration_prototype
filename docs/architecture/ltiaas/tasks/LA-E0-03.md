## Goal

Build the golden capture and compare tool and capture G1–G4 at G-BASE. Every E1 step and E4 then proves "no behaviour change" by a compare that runs without Docker. A difference passes only when an `LA-IC` expected-delta file names it.

## Scope

- In: G1 (API documents), G2 (simulator transcript per channel for one fixed script), G3 (app API transcript of the same script), G4 (tool error pages, learner labels, player status texts); normalization; compare; the expected-delta format; the U1 seed state.
- Out: a per-scenario record diff over the 394 M1 rows (LD-7: only if a reviewer shows a gap).

## Design notes

- The golden script makes one connection per baseline channel (Moodle-shaped standard provider, Canvas sim, Blackboard sim), one publication each, a Deep Linking pick, learner launches and grades. Its attempts leave score sync rows in every status (`sent`, `pending`, `failed`, `conflict`, `superseded`), because U1 (LA-E1-06, LA-E4-02) needs them.
- Expected-delta file: `tests/ltiaas/golden/expected/<LA-IC id>.json`, one entry per field path with the new value or a value rule. Both reviewers approve each file at the task that ships the change (LD-9).
