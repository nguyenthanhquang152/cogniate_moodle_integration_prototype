## Goal

The Cogniate app gets the building blocks for named, accountable operator commands: an append-only audit table, one audit writer, an operator policy module (who may run a command, which evidence it needs) and a read-only `app:audit list` command. Lane K wires them into the grant and binding commands in LA-E5-12.

## Scope

In:
- App table `audit_event` (data model §5): `library_id` where the LTI service table has `tool_account_id`; append-only trigger (`audit_event is append-only`).
- Audit writer: `insert` and `list` only; `details` at most 4 KB after `redact()`; never a grant code, key, token or note text.
- Operator policy (LA-ADR-07 D4): reads `STACK_PROFILE` of the CLI process.
  - `production`: `--operator` is required and must be in `OPERATORS` (comma list) or `OPERATORS_FILE` (JSON array); `--evidence-channel` and `--evidence-ref` are required.
  - `default`, `acceptance`: all optional; the actor defaults to `OPERATOR_NAME`, else `unknown`.
- Evidence validation (LA-ADR-07 D5): channel in `institution-email`, `support-call`, `lms-admin-ticket`, `other`; `verified-admin-launch` is refused for operators; `--evidence-ref` 1–200 characters.
- `npm run app:audit -- list [--connection <id>] [--action <a>] [--since <ISO>] [--limit <n ≤ 500>]`: one JSON line per event, newest first, no note text; it writes no event.

Out:
- The flags and the event writes inside `app:grant` and `app:binding` (LA-E5-12, lane K).
- The `verified-admin-launch` evidence that the system writes (LA-E6-03).

## Design notes

- Contract (BD-A2-45): the app `audit_event` has `connection_id` (nullable, index `(library_id, connection_id, ts)`) and `client_ip` (nullable, `NULL` for CLIs); `target` stays the changed object. `app:audit list --connection <id>` filters on `connection_id`. The table has the append-only trigger and the `INSERT OR REPLACE` guard. `app/audit` exports `insertAuditEvent`, `listAuditEvents` and `withAudit` with the LTI rules (LA-ADR-06 D4 T0–T5, BD-A2-29), `libraryId` and `connectionId`; the details limit is the LTI rule (`{"truncated": true}` above 4 KB after `redact()`, never an error). A trace id for each CLI run. A1 adds the two columns and the guard to the data-model §5 sketch.
- The policy module returns a decision (allowed, actor, evidence fields) or one refusal line; the CLI prints the line and exits 1 (LA-E5-12).
- `app:audit list` is a read-only command, so QA may run it through `docker compose exec` (tasks README §2).
