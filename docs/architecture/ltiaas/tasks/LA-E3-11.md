## Goal

The scores and line item API passes AGS extras to the platform and back: `submission` times, `scoringUserId`, and extension members whose key is an absolute https URL. Today the service drops them (`services/lti-service/src/platform/ags.ts:96`). Whether the AGS reporter sends them is an E4 decision (A1).

## Scope

In:
- `POST /api/lineitems/:id/scores` accepts optional `submission` (`startedAt`, `submittedAt`, ISO 8601), `scoringUserId` (string), and up to 8 members whose key is an absolute https URL, each value at most 4 KB of JSON. The service sends them to the platform unchanged.
- Scores `GET` returns `scoringUserId` and the URL-keyed members of each result. Line items keep URL-keyed members both ways.
- A member whose key is not an absolute https URL is dropped, as today.

Out: `scoreGiven: null` (LA-E3-12, Could); the reporter's use of the fields (A1, E4).
