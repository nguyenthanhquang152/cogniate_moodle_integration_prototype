## Goal

Every Cogniate channel asks only for the four AGS scopes. The capability `registration.scopes` of each baseline channel gets that list; the Canvas developer key JSON and the Dynamic Registration `complete` call take it from the capability; the Moodle manual tool configuration row 13 says "Do not use this service". This is the intended change LA-IC-04.

## Scope

In:
- `registration.scopes` = `lineitem`, `lineitem.readonly`, `result.readonly`, `score` (the AGS scope URLs, this order) for `moodle`, `canvas`, `blackboard`.
- The Canvas JSON `scopes` is the channel's `registration.scopes` (both `jwk` forms).
- Moodle manual row 13 (`nrps`) value: "Do not use this service" (the Moodle 5.2.4 option label; QA confirms the exact text).
- The app's Dynamic Registration POST sends the channel's `registration.scopes` in `complete.scopes`.

Out: `lti-generic` and `brightspace` get the same value in A1's E2 manifest tasks (K); the Blackboard admin guide text "grade service on; membership service off" (Docs, E8); the LTI service field (LA-E3-06).
