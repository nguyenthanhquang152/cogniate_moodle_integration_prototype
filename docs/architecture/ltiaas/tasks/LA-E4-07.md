## Goal

The app exposes `GET /metrics` (OpenMetrics text) and `GET /readyz` on an operator listener that the proxy does not route, so the runbook signals of A2's operability file have data. Values never hold session or tenant data.

## Scope

- In: the listener (default `127.0.0.1:4210`; the `acceptance` compose binds it on the stack network), the metrics of app API delta §8a, `/readyz`.
- Out: LTI service metrics (A2 LA-E5-17); alerts (runbook text, E8).

None beyond app API delta §8a.
