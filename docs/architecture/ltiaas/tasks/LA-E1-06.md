## Goal

Add the app migration with `connection.channel`, `connection.binding_authority`, `binding_attempt.target_kind` and `binding_grant.bound_values` (design number `013`). The connection repository maps `channel` and the authority; it no longer gives `lms` to any other code. Every core read of `lms` moves to the channel, the registry, the capabilities or the stored authority. The connection DTO and the `lms-providers` entries get `channel`, `channelName` and `channelCapabilities` (LA-IC-01).
