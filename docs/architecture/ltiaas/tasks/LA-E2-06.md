## Goal

D2L administrators can start a Dynamic Registration. Because the D2L token host is off the issuer origin, every `brightspace` DR is staged: the LTI service creates an inactive platform, and an operator grant with `--accept-staged` and `--confirm-foreign-hosts` activates it. The change is data in the channel folder only.
