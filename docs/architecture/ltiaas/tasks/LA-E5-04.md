## Goal

A tool account gets a status (`active`, `suspended`, `closed`), its own tool URLs, per-account limits and a stored claim policy. Operators manage accounts through the operator API. One account resolver module builds every protocol URL, so a later host mode (LG) is one change.

## Scope

In:
- Columns `status`, `status_changed_at`, `public_base_url`, `limits`, `claim_policy`, `service_key_write_scope` with the defaults for old rows of LA-ADR-06 D2.
- Operator-settable `launch_url`, `deep_linking_url`, `registration_url` with the URL rules of D2.
- `publicBaseUrl` is kept but refused when not `null` (`400 INVALID_REQUEST`, field `publicBaseUrl`): LA builds path mode only.
- `claimPolicy`: shape check and storage only (LA-ADR-05 D7 shape); the launch effect is LA-E3-10.
- `limits`: shape check and storage; LA-E5-03 reads it.
- Endpoints `GET`, `POST /operator/v1/accounts`, `GET`, `PATCH /operator/v1/accounts/:id`, and `POST /operator/v1/accounts/:id/shared-platforms` (contract delta §3), with their audit events.
- A new account writes the SHA-256 of 32 random bytes that nobody holds into the frozen column `api_key_hash` (A-LAD-14) and gets its first `active` signing key.
- Close: final; revokes every API key and service key of the account in the same transaction.
- Account resolver: `resolveAccount(request)` and `protocolUrls(account)`; path mode `{PUBLIC_LTI_URL}/lti/{login|launch|keys|register}/{accountId}`. The `Account` answer has `protocolUrls`.

Out:
- Protocol status pages, the JWKS `404` of a closed account and the resolver call sites (LA-E5-06, lane L).
- API key table, issue and revoke endpoints (LA-E5-07). Account purge job (LA-E5-20).
- `lti:shared-platform` as an API client (LA-E5-05).

## Design notes

- Close before LA-E5-07 lands: the account's `api_key_hash` is replaced by an unusable hash. After LA-E5-07, close revokes every `api_key` row. AC-LA-E5-04-08 runs after LA-E5-07.
- `PATCH` with `status: closed` is final: a later change gives `409 ACCOUNT_CLOSED` (contract delta §3).
- `account.status` is the audit action when `status` changes; other field changes are `account.update` (contract delta §5).
- The bootstrap of `cogniate` keeps the tool URLs from `PUBLIC_APP_URL` (`services/lti-service/src/store/accounts.ts:45-47`).
