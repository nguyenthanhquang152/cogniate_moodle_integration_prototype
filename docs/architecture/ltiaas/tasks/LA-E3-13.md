## Goal

The service checks the required fields of each content item type before it signs a Deep Linking response (DL 2.0 per-type rules). Cogniate sends only `ltiResourceLink` items, so the Cogniate app sees no change; other tool back ends get a clear `400`.

## Files

| May edit (exclusive) | Must not edit |
| --- | --- |
| `services/lti-service/src/lti/deep-linking.ts` | every other file |

## Scope

In: `link`, `image` and `file` need an https `url`; `html` needs a string `html`; else `400 INVALID_CONTENT_ITEM` with the item index in `description`. `ltiResourceLink` is unchanged.

Out: custom content item types (DL-18, not in LA).
