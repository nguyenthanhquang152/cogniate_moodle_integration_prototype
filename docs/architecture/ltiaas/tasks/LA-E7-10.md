## Goal

One command, `npm run ci:local`, runs the release checks on a clean clone: install without scripts, `npm run check`, a vulnerability scan, an SBOM and a secret scan of every tracked file. There is no hosted CI service in LA.

## Files

| May edit | Must not edit |
| --- | --- |
| New `infra/scripts/ci-local.sh` and its test `infra/scripts/ci-local.test.mjs` | Root `package.json` (K: the `ci:local` line by RQ-1); `infra/compose.yaml`, `infra/scripts/lib.sh` (S) |

## Scope

- In: the five steps of README §4a in order; the network rule (exit 2, `network_unavailable`); one output line per step; the reviewed allow list in the script.
- Out: image signing, base-image digest pins (LG).

## Design notes

- Step 5 follows the row "Step 5 rules" of README §4a (BD-A1-05, answer to the lane R question of 2026-10-22): rule 4 checks only the secret keys of `.env.example` (its `# --- secrets` section) in other files, and every key in `.env.example` itself; the 64-hex rule skips `docs/**`; allow-list entries are file + rule id + SHA-256 of the value + reason, with no line numbers; an unused entry is a note, not a failure.
