## Goal

The channels whose connection check is useful get the manifest flag `setup.connectionCheck: true`: `canvas` and `lti-generic` (LA-ADR-08 D6). The portal then shows the "Check connection" button (LA-E6-01), and the app route accepts the check.

## Files

| May edit (exclusive) | Must not edit |
| --- | --- |
| `packages/channels/canvas/manifest.ts`, `packages/channels/lti-generic/manifest.ts` (value `setup.connectionCheck` only) | `apps/portal/**` (P: LA-E6-01); every service file |

## Scope

In: `setup.connectionCheck: true` for `canvas` and `lti-generic`. Out: `moodle`, `blackboard` (shared platform: the check proves only the vendor application, LA-ADR-08 D4), `brightspace` (no value in LA).
