## Goal

QA-E2E proves the portal shell and the platform storage launch in a browser: manifest-driven cards and wizards for every channel, one Deep Linking and score flow per new channel, and a launch inside the simulator LMS frame with the state cookie blocked.

## Scope

- In: U1–U4 of TEST-STRATEGY §2.4 for every registered channel (U3 only for new channels).
- Out: U5 keyboard and axe checks (Could, LA-E7-12).

## Design notes

- U4 removes the state cookie from the framed launch request with a route rule (Chromium keeps a `Partitioned` cookie in a frame, so the browser setting alone does not reach the storage path). qa.md records the method.
