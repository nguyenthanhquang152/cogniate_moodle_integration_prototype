## Goal

Each launch or Deep Linking refusal that names a connection writes one connection event, so the health view shows the last refusal and its reason without a log search.

## Files

| May edit (exclusive) | Must not edit |
| --- | --- |
| `services/cogniate-app/src/tool-pages/launch.ts` (B3 window; one writer call per refusal site) | `services/cogniate-app/src/domain/connection-events.ts` (P: LA-E6-02; this task only calls it) |

## Scope

In: one call of `recordConnectionEvent` at each refusal with the reasons `site_mismatch`, `lms_mismatch` and `deployment_not_approved`, for launch (kind `launch_refused`) and for Deep Linking (kind `deep_link_refused`), with the code and the trace id. The page and the log line stay as today. Out: refusals that name no connection (no event); the check events (LA-E6-01).
